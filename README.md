## ✨ What is this?

This is my personal developer portfolio — built without a frontend framework so the visual system, interactions, responsiveness, and page behavior remain directly controlled in the source.

The site presents my background, technical stack, projects, experience, and contact information through a deliberately **retro terminal / pixel-cyberpunk** interface.

---

## 🎮 Experience & Interactions

- 🧭 Smooth section navigation
- 🔎 Skill search that highlights matching content
- 🌓 Theme control
- 🖱️ Custom pixel-style cursor and cursor trail
- 🌊 Animated background wave canvas
- 📱 Responsive navigation with mobile menu behavior
- 💥 Pixel/glitch-inspired hover effects
- 🎯 Interactive project cards and external links
- 📊 Project/experience statistics presentation
- ⌨️ Terminal-inspired hero panel

## 🏗️ Architecture

```text
Browser
   │
   ▼
index.html
   │
   ├── Semantic page sections
   ├── Navigation / project links
   ├── Inline CSS visual system
   └── JavaScript interactions
          │
          ├── Cursor + trail
          ├── Wave canvas
          ├── Skill search
          ├── Theme controls
          ├── Responsive menu
          └── Project navigation
```

The project intentionally keeps the architecture simple: the browser loads the static HTML document and its assets, while JavaScript handles client-side interaction and visual effects.

## 🚀 Run Locally

Because this is a static site, no package manager or build step is required.

### Option 1 — Open directly

Open `index.html` in a browser.

### Option 2 — Local HTTP server

With Python installed:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

### Option 3 — VS Code

Use a static-server extension such as Live Server and open `index.html`.

## 🎨 Visual System

The UI is built around a small set of reusable visual primitives:

```text
BLACK       → primary background
PINK        → navigation, accents, emphasis
GREEN       → active/status elements
WHITE       → primary readable text
GREY        → secondary metadata
```

Typography intentionally uses pixel/terminal-inspired fonts to reinforce the developer-console aesthetic.

## 🛠️ Development Notes

The portfolio deliberately avoids a framework dependency. This makes the page easy to host as static content while keeping the animation and interaction layer close to the browser APIs.

When modifying the project:

1. Preserve the existing CSS variables and visual tokens.
2. Keep responsive behavior intact.
3. Test navigation and interactive effects after UI changes.
4. Keep external project links current.
5. Keep `km-logo.png` available at the path used by the favicon declaration.
